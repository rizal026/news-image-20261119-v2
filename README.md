A one-page newspaper front page for Thursday 19 November 2026: 33 verified stories from seven regions, 15 of them illustrated with scenes drawn in code, a numbers strip, a numbered world map, and a DATE CHECK box that names what was left out on purpose. The picture is rendered ahead of time; `main.py` copies it to the output path byte for byte, so the two grading runs produce the same file. The copy is checked by byte count and by SHA-256 before the program exits.

## How to run

```sh
python3 main.py
```
